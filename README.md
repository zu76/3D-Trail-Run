# 3D Trail Run

A project to generate 3D terrain maps of trail running routes.

## Overview

This project aims to visualize trail run courses as interactive 3D terrain maps, combining GPS/GPX route data with elevation and topographic information.

## Goals

- Parse and process GPX/GPS trail run data
- Generate 3D terrain meshes from elevation data (DEM/SRTM)
- Render interactive 3D maps with the trail route overlaid
- Export visualizations as images or interactive web experiences
